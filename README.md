Unity virtual-reality game module for an immersive gravity-car simulator.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Gameplay.unity](https://github.com/kleberandrade/gravity-car-vr-game/blob/master/Assets/Scenes/Gameplay.unity).

## Recorded requirements

- Recorded Unity Editor: **2019.1.4f1** in [ProjectSettings/ProjectVersion.txt](https://github.com/kleberandrade/gravity-car-vr-game/blob/master/ProjectSettings/ProjectVersion.txt).
